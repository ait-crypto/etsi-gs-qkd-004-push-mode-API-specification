Server description of the QKD endpoint for processing ETSI GS QKD 004 push mode requests

etsi004

open key stream

The open-connect message connects a KMS to the QKD Device. As per sequence definition, the QKD device will assign the key_stream_id at the source node, therefore null has to be given as key_stream_id parameter.The QKD can suggest alternative QoS due to its capabilities. At the destination, the key_stream_id has to be specified to the same given at the source.

Request Body schema: application/json
required
source
required
string <uri>

the source URI of the request.

destination
required
string <uri>

the destination URI of the request.

key_stream_id
string <uuid>

key stream ID. If null specified it is up to the QKD device to define the UUID

required
object (qos)

All values according to ETSI GS QKD 004 specification. If KMS does not want to specify a parameter, it is up to the choice of the QKD. Either the value is given as "null" or not present.

Responses

https://qkd_server/api/v1/kms/etsi004/open-connect
